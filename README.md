# PavelCraft

Персональный сайт Павла — тренера по хастлу в Москве. На странице размещены информация о тренере, направления занятий, стоимость, условия аренды зала, фотографии, видео и ссылки для связи.

## Запуск

Проект написан на HTML, CSS и JavaScript без сборщика и сторонних зависимостей. Для просмотра достаточно открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Сайт будет доступен по адресу <http://localhost:8000>.

## Структура

- `index.html` — разметка и содержимое страницы;
- `styles.css` — оформление и адаптивная вёрстка;
- `script.js` — меню, анимации, термины и ссылки на социальные сети;
- `assets/photos` — фотографии;
- `assets/posters` — обложки видеороликов;
- `assets/video` — подготовленные для сайта видео.

Ссылки на Telegram и ВКонтакте задаются в объекте `SOCIAL_LINKS` в начале `script.js`.

## Развёртывание

После первоначальной настройки сервера сайт обновляется вместе с FormaCode и
FormaCodeBot одной командой из любого из трёх локальных репозиториев:

```bash
make deploy
```

Команда подключается к серверу по SSH и запускает общий безопасный обновлятор.
