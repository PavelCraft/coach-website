# Сайт тренера Павла

Первая страница персонального сайта — индивидуальные занятия хастлом в Москве.

На странице используются пять локальных H.264-роликов, включая запись первых занятий студентов МГУ. Версии для публикации находятся в `assets/video`, подготовлены для потокового воспроизведения и вместе занимают меньше 80 МБ. Тяжёлые исходники хранятся только локально и исключены из Git.

## Как посмотреть

Откройте `index.html` в браузере. Для локального сервера можно выполнить:

```bash
python3 -m http.server 8000
```

После этого страница будет доступна по адресу `http://localhost:8000`.

## Что заменить перед публикацией

- ссылки на Telegram и ВКонтакте — в объекте `SOCIAL_LINKS` в начале `script.js`;
- при необходимости уточнить стоимость аренды конкретного зала.

Личные фотографии лучше оптимизировать в WebP/AVIF и хранить на сайте. Видео разумнее встраивать с видеохостинга: это ускорит загрузку страницы и не потребует дорогого видеотрафика с хостинга сайта.
